# Shatterstar

**Less Interface. Still the Whole Job.**

Shatterstar helps product teams decide what to remove, combine, hide or defer while preserving essential tasks—including rare but critical actions.

## The Problem

Products grow. Three screens end up doing the work of one. Settings pile up. The first-time setup asks too many questions.

Cutting things sounds simple. But a feature few people use can still matter a great deal, such as a rare action that cannot be skipped.

## What This Does About It

Shatterstar is a skill: a folder of instructions you add to an AI agent. It helps a team decide what to remove, combine, hide or put off. It starts from the tasks people must still be able to do.

You get ranked proposals, a check that each important task still works, the costs of each change and a plan to test it or undo it. Each proposal is compared with leaving the design alone or just making it clearer.

**Example.** In the project’s made-up example, three lists of outputs could become one page with filters, but only if finding, comparing, exporting and retrying still work. A gentler option is also offered: group the three links and change nothing else.

## Put It to Work

- **Overlapping destinations:** assess whether several output views can become one useful place.
- **Crowded settings:** distinguish everyday choices from advanced controls without losing access.
- **Long onboarding flows:** defer optional questions while keeping interdependent decisions together.
- **Feature retirement:** identify consumers, dependencies and replacement gaps before committing to removal.

You receive ranked proposals, task checks, tradeoffs and an experiment or rollback plan. Each proposal is compared with keeping or clarifying the current design.

## Make the Case for Simplification

Follow the [installation instructions](REFERENCE.md#installation) to add the complete skill folder to your agent. Supply tasks, interface artifacts and whatever evidence exists. Analytics are optional.

```text
Use $shatterstar-product-simplification to assess these duplicate output
views. Preserve retrieval, comparison, export and recovery. Compare
consolidation with keeping the views and clarifying their labels.
```
